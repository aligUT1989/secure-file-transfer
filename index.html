How do I get a token? (1 min)
  1. Open GitHub → Fine-grained tokens.
  2. Token name: anything. Expiration: your choice.
  3. Repository access → Only select repositories → pick your storage repo.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Click Generate token, copy it, paste it above.
